# 垢抜け13週

「3か月 垢抜け・生活改善ロードマップ」（2026-11-16〜2027-02-14）を、スマホで毎日使うためのWebアプリです。GitHub Pagesで公開し、ホーム画面に追加して使います。

## できること

- **今日**：毎日のチェックリスト7項目（まだ始めていない習慣は自動で「できた」扱い）、疲れた日モード（★3項目で合格）、睡眠・タバコ・コーラ・筋トレ・体重・腹囲の記録、シフト別の起床・就寝の目安
- **今週**：その週のテーマ・新しい習慣・食事・睡眠・運動・美容・コーラ・喫煙の目安、筋トレの重量、1回だけやるToDo、評価週（W4・W8・W13）の評価基準
- **グラフ**：週ごとの達成率（60%ライン付き）、睡眠・体重・腹囲・タバコ・コーラの推移と目標線
- **進捗表**：週ごとの合格日数・達成率・平均睡眠・体重・腹囲・筋トレ回数などを自動で集計し、13週の平均達成率も計算
- **設定**：開始日の変更、記録の書き出し・読み込み（JSON）

記録はスマホのブラウザの中（localStorage）に保存されます。サーバーには送られません。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る（例：`akanuke-13w`、Public）
2. 「Add file」→「Upload files」で、このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`icons`フォルダ、`README.md`）をすべてアップロードしてCommitする
3. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `(root)` にしてSave
4. 1〜2分後に `https://<ユーザー名>.github.io/akanuke-13w/` で開ける

## スマホのホーム画面に追加

- iPhone：Safariで上のURLを開き、共有ボタン →「ホーム画面に追加」
- Android：Chromeで開き、メニュー →「ホーム画面に追加」または「アプリをインストール」

## アイコンの変更

`icons/options/` に3案が入っています（a：プログレスリング、b：ステップアップ、c：チェック＋ダンベル）。初期設定は案Bです。
変える場合は、使いたい案のフォルダの `icon-192.png`・`icon-512.png`・`apple-touch-icon.png` を `icons/` に上書きし、`sw.js` の `VERSION` を1つ上げてください（例：`v1` → `v2`）。ホーム画面のアイコンは、一度削除して追加し直すと反映されます。

## 更新するとき

`index.html` などを書き換えたら、`sw.js` の `VERSION` を上げてからアップロードします。アプリを一度閉じて開き直すと新しい版になります。
